# 🎓 JavaProject - Gestion des Étudiants



## 📖 Description
Projet **Java orienté objet (POO)** pour la gestion des étudiants avec connexion à une base de données **SQL Server**.  
Ce projet permet de **Créer, Lire, Mettre à jour et Supprimer (CRUD)** des enregistrements étudiants dans la base de données.  
Développé avec **Eclipse IDE**.

---

## 🛠️ Technologies utilisées
- 💻 **Java** (POO)
- 🗄️ **SQL Server** (gestion des données)
- 🔌 **JDBC** (connexion Java ↔ SQL Server)
- 🖥️ **Eclipse IDE**

---

## ✨ Fonctionnalités principales
- ➕ Ajouter un nouvel étudiant
- 📋 Consulter la liste des étudiants
- ✏️ Mettre à jour les informations d'un étudiant
- ❌ Supprimer un étudiant
